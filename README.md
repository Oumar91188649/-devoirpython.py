# exercice 3 - Environnement Python 
## 1 . creer le dossier et l'environnement virtuel 
dans le terminal , depuis le dossier exzecice3 :
     ---bash 
    python  -m venv .venv 

    Si 'python' ne fonctionne pas sur macos/Linux :
     ---bash 
     python -m venv .venv
     ## 2 . Activer l'environnement 
     ### Windows CMD
     --- cmd 
     .venv/scripts/Actvate.psl
     ### macOS/Linux
      ---bash 
      source.venv/bin/activate
